# Format and workflow examples

All identifiers, protein sequences, Q3 labels, RHP sequences, and latent vectors here are synthetic. The latent vectors were drawn independently and are not outputs of a trained DeepRHP model. These files exercise interfaces and plotting; they do not reproduce dissertation results.

| File | Contents |
| --- | --- |
| `protein_sequences.csv` | Eight amino-acid sequences for window conversion |
| `protein_cytoplasm_z.csv` | Eight synthetic proteins, aligned Q3 labels, and five 16-dimensional window vectors per row |
| `protein_membrane_z.csv` | A second synthetic protein group with the same schema |
| `rhp_z.csv` | Eight synthetic monomer sequences and five window vectors per row |
| `groups.json` | Relative paths, colors, display labels, and explicit PCA-reference choices |

The example group names are labels for demonstrating the file interface. They do not describe experimentally annotated protein populations.
