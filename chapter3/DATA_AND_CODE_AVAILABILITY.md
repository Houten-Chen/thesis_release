**3.8 Data and code availability**

Protein sequence data were obtained from UniProtKB and MobiDB. Analysis code and documentation for this chapter are available at [https://github.com/Houten-Chen/thesis_release/tree/main/chapter3](https://github.com/Houten-Chen/thesis_release/tree/main/chapter3). The DeepRHP/AE-RHP implementation used for sequence embedding is available at [https://github.com/Shunili/AE-RHP](https://github.com/Shunili/AE-RHP). ESM2 and Porter6 are available at [https://github.com/facebookresearch/esm](https://github.com/facebookresearch/esm) and [https://github.com/WafaAlanazi/Porter6](https://github.com/WafaAlanazi/Porter6), respectively. Standard RHP sequence simulation code is available at [https://github.com/ivanjayapurna/RHPapp](https://github.com/ivanjayapurna/RHPapp).
